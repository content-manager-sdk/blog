The swagger definition file that is auto-generated by the ServiceAPI swagger UI is not particularly useful due to its large size and complexity, in fact it often causes swagger tools to crash.  For this reason it is better to handcraft an OpenAPI definition file to respresent the portions of the ServiceAPI you need.  The [sample](https://github.com/content-manager-sdk/Community/tree/master/Samples/ServiceAPI/Connectors/OpenAPI) is in the samples repo, the following video is a run through of making a change to the file and generating test code.
