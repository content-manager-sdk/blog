Microsoft made some big updates to the Azure Powershell CLI which necessitated changes to the zero footprint office setup script.  For those staying on with the older version of the CLI we have retained the older setup script, both can be found in the [documentation](https://content-manager-sdk.github.io/Community/101/zero_teams.html#zero_teams_script).
We have filled one of the gaps in our documentation with a new document on how to configure ADFS OpenID for native Content Manager, once again see the [documentation](https://content-manager-sdk.github.io/Community/101/oidc.html#oidc_adfs_native).
